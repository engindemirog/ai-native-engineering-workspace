# Prompt: Architecture Decision

```
We need to decide: <decision question>.

First DISCUSS: compare the realistic options for THIS project's context (team size, product
stage, constraints from docs/). Give your recommendation with rationale, list what would make
you change it (revisit triggers), and evaluate alternatives seriously — no strawmen.

After I decide, write docs/decisions/<NNNN>-<slug>.md using docs/decisions/TEMPLATE.md.
Consequences must include BOTH the benefits AND the costs. The test of a good ADR: someone in
6 months can answer "why did they do it this way?" from this file alone.
```
