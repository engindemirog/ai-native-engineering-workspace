# R-10 — Ambiguity / Docs–Code Conflict

```
There is an ambiguity or contradiction: <state it>.
DO NOT PROCEED ON AN ASSUMPTION. Bring me:
- The exact gap/conflict (both sides referenced: file + section).
- The options, each with its cost.
- Your recommendation and why.
After I decide: WRITE the decision into the correct source of truth (docs or spec — whichever
owns it), then continue from where you stopped. No code before the decision is recorded.
```
