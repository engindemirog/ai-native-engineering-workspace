## Risks & open questions
1. **REVIEW and VERIFY rows open the triage screen**, not the approval panel. Recommendation: the
   next step goes there, above the paste, since the review has to run before its report can be
   pasted; after a save, the answer box gives the step after it (`/build`, `/verify`) as today.
2. **Status's text for a row that waits on the agent** stays as it is; only the command is derived
   (G-1). A stage status adds later has no command until the table learns it — the screen then
   shows status's line alone, as today. A test pins the table to status's stage names.
3. **Continue during a review in the same project** opens a second Claude session beside the one
   that may still be building. Recommendation: accept; the screen says "a new session".
4. **Environment:** low memory: one selftest or npm run at a time.
