## Risks & open questions
1. **Merged is read from the default branch's AGENTS.md**, not from git ancestry: a squash-merged
   PR leaves `chore/bootstrap` unmerged by ancestry forever. Recommendation: merged = the default
   branch (the remote's HEAD, else a local `main` or `master`) holds a configured AGENTS.md; the
   screen says "pull the default branch" while the merged PR is not pulled.
2. **Doctor's verdict goes stale** when the files change. Recommendation: kept with HEAD and
   `git status --porcelain`; any change shows "run doctor again".
3. **A project bootstrapped before 0014** has a configured AGENTS.md on its default branch: the
   section never shows — as today.
4. **Claude Code passes a command's arguments only through `$ARGUMENTS`**; Copilot, Cursor and
   Codex receive the typed text with the prompt. Recommendation: `$ARGUMENTS` in the Claude Code
   command; the others read "the arguments typed after the command" — the human's run checks
   Claude Code (AC-6), the unit test checks every file holds the rule.
5. **Environment:** low memory: one selftest or npm run at a time.
