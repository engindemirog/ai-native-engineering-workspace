## Risks
1. **Tags and a release are outward-facing and stay visible.** Only existing, merged commits are
   tagged; a wrong tag is deleted and re-pushed before anyone pins it. Recommendation: accept.
2. **6 months is a promise to organizations.** It is the shortest period that covers one training
   cohort and its first project. Recommendation: 6 months; your call if a contract says otherwise.
3. **Branch protection for `lts/1.24`** (no direct push, PR + CI) is a GitHub setting, not a repo
   file. Recommendation: you set it once in the repository settings; this plan does not.
