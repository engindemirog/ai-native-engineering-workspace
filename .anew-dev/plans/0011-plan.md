## Risks & open questions
1. **This repo is the template**: its AGENTS.md is `NOT CONFIGURED`, so opened here the screen
   offers only "Set up the project". Recommendation: that is right for a template copy; the AC-6
   run uses a fresh copy outside the repo, and the pilot copy (configured) shows the kinds.
2. **What init writes** is listed in the confirmation from `setup.ts`, not read from init.
   Recommendation: a test that runs the real `scripts/init` in a temp copy for each adapter and
   compares the files it wrote with the list, so the list cannot drift.
3. **A partly installed adapter** (the marker there, other files missing): it counts as installed,
   as doctor counts it. Recommendation: keep doctor's rule; a refresh is the terminal's `--force`,
   named on the card.
4. **Windows and `scripts/init`**: run through the POSIX shell found for gate (`anew.shell`); no
   shell → no Install, the same notice as gate's.
5. **Environment:** low memory: one selftest or npm run at a time.
