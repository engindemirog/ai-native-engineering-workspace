## Ordered steps
Scripts first, documents describe what exists.

1. **doctor: new ships.** Reuse the immutability block's base ref. New ships =
   `git diff --name-status <base> -- specs/done/` lines with status `A` (a move from `active/`
   shows as `A` under this pathspec), plus untracked files there when base = HEAD. For each:
   criterion lines `^- \[ \] (AC|CB|PB)-[0-9]+` without `→ moved to` → gate "unproven
   criterion in a new ship: <file> <id> — prove it or move it out at the ship gate (R-08)".
   `→ moved to B-<n>` → `B-<n>` must appear as `**B-<n>**` in `specs/backlog.md`; `→ moved to
   spec <NNNN>` → a `<NNNN>-*.md` in `active/` or `done/`; else gate. A spec with a
   `Sensitive area:` line and any move → gate "a sensitive-area criterion cannot be moved out".
   Selftest for AC-1…AC-4 (fixture commits a spec in `done/`, then adds a new one). `[plan 0002/1]`
2. **doctor: self-critique.** `- Self-critique: pending …` in `specs/active/*.md`: Draft → WARN
   with the condition; Approved / In progress → gate. `done` or no field → nothing. Selftest
   for AC-5. `[plan 0002/2]`
3. **Templates + spec prompt + R-08.** Field, move-line format, Triage section. `[plan 0002/3]`
4. **Workflow, verify, testing rule 6, PR template, flaky-test wording, commands.md.** `[plan 0002/4]`

## Risks & open questions
- Environment: no prerequisite needed (POSIX sh, git, awk, sed); doctor verdict on this
  machine — this repo has no check.conf, so no profile verdict is printed.
- **Q1 — Untracked new ship when base = HEAD.** `git diff HEAD` does not list untracked files.
  *Recommendation:* add `git ls-files --others --exclude-standard specs/done/` locally; CI never
  has untracked files, so it changes nothing there.
- **Q2 — Unicode arrow `→` in grep.** Locale-dependent matching of a multibyte character.
  *Recommendation:* match the byte sequence with `grep -F '→ moved to'` (fixed string, no
  class), which is byte-exact in every locale; also accept ASCII `-> moved to` so a keyboard
  without `→` is not a trap. Selftest covers both.
- **Q3 — A criterion line spanning several lines** (wrapped text): the marker may sit on a
  continuation line. *Recommendation:* the marker must be on the `- [ ] AC-n` line itself;
  the template's format comment says so; doctor reads only that line.
- **Q4 — ADR number.** ANEW-0012 assumes PR #5 (ANEW-0011) merges first; this branch is on top
  of it. *Recommendation:* keep the stack; if #5 changes, rebase this branch's numbers then.
